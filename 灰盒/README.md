# 学院路二维数据局部灰盒

## 可玩室外原型

直接打开 [试玩.html](试玩.html)，无需安装引擎或启动服务器。WASD / 方向键四方向移动，Shift 快走，E 互动，M 查看地图，Esc 关闭窗口；下方提供触屏按钮。角色参考用户的黄色绿眼睛形象，由内置 imagegen 生成透明素材，使用单张精灵加步行摆动与朝向标记。素材与提示词见 `assets/README.md`。

三个室外区块为公寓与食堂、图书馆与绿园、博物馆周边。靠近青色路口标记后按 E 切换，反向标记可以返回。橙色地点支持查看介绍和本次会话的探索计数。室内维持暂缓，路口和查看点都是游戏安排，未标作真实建筑入口。

原型参数：角色绘制框 24 × 36 px（较上一版宽高缩小约45%），脚部碰撞圆半径 5 px，步行 125 px/s、快走 200 px/s，交互半径 48 px。角色采用地图图标式放大比例，不按源地图米制解释身高。交互需要无遮挡视线，菜单暂停移动；切换必须主动按 E，避免反复自动触发。

每天分上午、下午、晚上。走路、切换区块、看地图和地点介绍不消耗时段；顶部“休息至下午/晚上”经确认推进一个时段，晚上需去8公寓结束一天。下午和晚上有轻微光照色调变化。靠近8公寓按 E，选择“睡觉并保存”即可结束剩余时段，进入次日上午并保存日期、时段、区块、位置、朝向和已探索地点。

存档使用当前浏览器的 localStorage（键 `buaa-campus-progress-v1`，结构版本2，自动兼容旧版1），重新打开同一地址自动读取最近一次睡觉存档。白天尚未睡觉的进度不会自动写入；“回到起点”只移动位置。更换浏览器、移动页面地址或清除站点数据不会自动迁移存档。保存失败时保持当前日期并提示重试；损坏或不兼容的存档会提示并从第1天启动，读取时不覆盖原记录。

运行时直接使用源要素的 36 个建筑/水体多边形（保留内环），而非 Tiled 的粗格碰撞层。`engine.js` 以小步进检测运动防止穿墙，限制区块边界。`world.js` 由 `python tools/build_playable.py` 导出，`play.js` 提供输入、镜头、交互、切换与画面。源灰盒重建后如源数据有变，请同时重新导出运行数据。

检查：`node tools/check_playable.cjs` 验证多边形内院、墙边、快速位移与所有路口/互动点可达；`tools/check_browser.cjs` 使用临时目录的 Playwright 和本机 Edge，验证移动、碰撞、地点、区块切换和地图暂停。`tools/check_progress.cjs` 验证三个时段、取消操作、睡觉、存储失败、浏览器进程重启后的恢复，以及损坏存档的处理。

本轮只重做室外场景。源文件取自用户的 [buaa-simulator 仓库](https://github.com/RobertYoung446/buaa-simulator/tree/59df24233b64aa0b463fde531ac87051556c5a08/地图数据/二维版本)，与本地 `地图数据/二维版本/xueyuan.tmj`、`xueyuan.map.json` 的 Git 内容哈希一致。采用学院路校区是沿用上一版校园灰盒的校区范围；室内暂不参与设计。

## 查看

- 打开 [预览.html](预览.html)，用地点按钮定位图书馆、7/8 公寓、东区食堂、航空航天博物馆和第九馆。橙色轮廓来自这些建筑在二维数据里的多边形。
- `campus.svg` 保留源 SVG 的道路、绿地、水体、建筑形状和名称，仅更改视窗并突出选定要素。
- `campus.tmj` 是从学院路 Tiled 地图逐格裁出的可编辑文件。`ground` 与隐藏的 `collision_draft` 与源数据对应；`source_landmarks` 对象记录源要素 ID 和名称，不是门或交互点。
- `campus-overview.png` 为栅格速览；无名称标注，以 SVG/预览页核对位置。
- `campus-labeled.png` 为当前 SVG 的完整截图，方便直接查看选定建筑和周边标签；地图编辑仍以 SVG 与 TMJ 为准。

## 裁剪范围与比例

| 项目 | 数值 |
| --- | --- |
| 源校区地图 | 150 × 148 格 |
| 本区块 | 64 × 42 格，左上源格坐标 `(55, 39)` |
| 源地图网格 | 8 米/格，32 × 32 px/格 |
| 区块覆盖 | 约 512 × 336 米的示意范围 |

这套 `8 米/格` 是源数据的地理网格，**不是角色或家具比例**。源 Tiled 碰撞层按格中心采样，仅是初稿；试玩页改用多边形轮廓。现实建筑入口、门禁仍需人工核对。静态预览页用于查看地图，移动在试玩页进行。

当前地图包含图书馆及其西侧绿地、几栋公寓、东区食堂和航空航天博物馆周边的原始相对位置，解决了上一版任意重排建筑的问题。图中没有被数据确认的“社团活动室”或建筑入口，因此没有添加对应标记。之后选定具体可玩区块和入口，再按角色比例制作游戏瓦片。

## 再生成与来源

运行 `python tools/generate_graybox.py` 可从本地二维源文件重新生成 `campus.tmj`、`campus.svg`、速览 PNG 和预览页。此命令只改写当前室外输出，不碰室内。源文件保持在 `地图数据/二维版本/`，旧版室内和早期手绘校园体块移至 `灰盒/旧版草稿/`，不属于当前场景。

## 航空航天概论与抓人任务

一天体验：上午到东区食堂按 E → 选择“开始在食堂上航概，真下饭！” → 课程消耗一个时段，接到老师的委托 → 找齐10名静止的逃课同学 → 回8公寓睡觉并保存，进入次日上午。若晚上开课则使用晚上时段，仍需睡觉才能进入次日。

开课前目标不出现；开课后生活区4名、图书馆区3名、博物馆区3名，按 M 查看紫点。目标以固定位置出现，脚部距离不超过10 px且中间无遮挡即可自动抓住，不需要 E。目标被抓后消失且不重复计数；地图或对话打开时暂停抓取。抓满10人自动弹出结算，本次课程不能重复领取或重开。

睡觉存档记录课程状态、开始/完成日期与已抓目标 ID。中途睡觉可次日继续，位置保持一致；未睡觉刷新仍回到最近的睡觉存档。课程代码见 course.js；check_course.cjs 验证按钮原文、开课耗时、移动抓取、重复接触、任务部分/完成状态读档及旧存档迁移。
