# 校园二维地图初稿

从归档 GeoJSON 的平面轮廓生成，原始 OSM 和 GeoJSON 文件保持不变。本目录是可编辑地图素材，尚未包含人物、像素美术、室内或可玩的游戏。

## 查看

打开根目录 `地图预览.html` 可切换三个校区。直接打开 `*.svg` 可以查看精确轮廓；`*.tiles-preview.png` 是粗网格栅格预览。

## 文件

每个校区使用 `xueyuan`、`shahe`、`hangzhou` 前缀：

- `*.map.json`：局部二维像素坐标、稳定地点 ID、原始属性及来源元数据。Polygon 内环和 MultiPolygon 保留。
- `*.svg`：可缩放底图，建筑内院使用偶奇填充；虚线是架空屋顶轮廓。建筑名称是辅助标注，可能重叠。
- `*.tmj`：Tiled JSON 地图，含 ground、默认隐藏的 collision_draft，以及供人工编辑的 gameplay_manual 对象层。
- `*.collision.json`：行优先碰撞网格（0 表示未分类/未阻挡，1 表示建筑或面状水域），以及保留内环的原始二维障碍多边形。
- `*.tiles-preview.png`：示意瓦片预览，非正式游戏美术。
- `tiles.png`：六种纯色示意瓦片图集，属于本项目生成的辅助素材。
- `转换清单.json`：校区尺寸、要素数、碰撞单元数和源文件 SHA-256。

## 坐标与比例

默认 4 像素/米、8 米/瓦片，即 32×32 像素瓦片。地图西北角为原点，x 向东、y 向南。使用本地等距圆柱近似投影，只适用于校园尺度的示意游戏地图。坐标转换参数均在 metadata 中；非测绘投影。

学院路使用上游 bbox；沙河、杭州使用北航校园边界的包围矩形，并添加 40 米边缘。矩形之外的不相交要素不进入二维结果，相交要素保留完整轮廓，坐标可能超出画布。原始数据保留全部要素。

复现命令（Python 3，无第三方依赖）：

```sh
python tools/convert_maps.py
```

可选 `--meters-per-tile 4 --pixels-per-meter 8` 提高网格密度，二者乘积须为正整数。会覆盖生成文件；先保存人工编辑结果。建议人工编辑另存到游戏地图目录。

## 人工编辑要求

网格按单元中心采样，细小建筑、窄墙、路边障碍可能遗漏；0 不保证可以通行。道路以中心线示意，不表示实际路宽。未知校园边界、建筑门口、门禁、台阶、室内和出生点不会自动推断。原数据包含校外周边要素，正式游戏需裁剪范围。

架空飞翔屋顶和 `building=roof` 仅作视觉参考，不进入碰撞；其他整体楼群与楼体重叠轮廓仍可能堵住真实通道，需要人工处理。建筑和水域原始多边形保留，方便使用比瓦片更精细的碰撞。首版请优先人工编辑学院路宿舍—教学楼—食堂—活动室区域。
