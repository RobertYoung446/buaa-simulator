# 全校版补充说明

全校版已覆盖教学、生活、家属、运动、大运村及南侧科研区域；新增范围的大多数楼体仍为地图轮廓模型。博物馆已恢复完整地图进深，不再按旧样区边界截断。下文记录此前各场馆的研究依据，其中“样区”指早期版本。

# 数据来源与还原精度

更新：2026-09-10。体育馆、游泳馆已做照片参考模型；本轮新增音乐厅南立面与博物馆入口。其余建筑没有同时完成逐栋校核。

## 首版为什么不像

首版从 OpenStreetMap 获取建筑平面、位置和道路，有层数的建筑按层高换算，没有高度的按用途估算，再统一挤出平屋顶并添加窗格。这能保留地理布局，却无法表达场馆的异形屋顶。首版对这两栋建筑的建模简化过度，不能把这一问题全部归因于地图数据。

原始数据保存在 `data/source.osm`，转换后的数据为 `data/campus.geojson`。照片参考模型独立位于 `src/landmarks.js`，没有把推测尺寸写回原始地图标签。

## 怎样获得更准确的模型

普通地图主要补充平面轮廓，换一个地图源通常不能直接得到异形屋顶。更有效的组合是：地图定位，建筑图纸约束尺寸，多角度照片或全景校核外形。

- 北航曾发布两校区的 720° 全景，可继续用于逐栋核对立面与空间关系：[2020 年北航官方发布报道](https://m.thepaper.cn/newsDetail_forward_8251896)。全景照片本身不是可直接导出的三维模型，也需注意拍摄年代。
- 本轮公开检索尚未找到可直接下载且确认属于学院路校区的完整 BIM、CAD 或点云。不代表学校内部没有这些资料。
- 若后续能取得建筑平面、立面、剖面或竣工 BIM，可显著提高尺寸和屋顶精度。没有图纸时，多角度现状照片也能进一步改善辨识度，但零散网图不能保证测量精度。

这两座场馆暂时不需要补照片即可完成本轮外形修正；后续若需要更高精度，最有价值的是屋顶俯视、背面与侧面全貌，以及带已知尺寸的参照。其余周边楼体应逐栋走同样的证据校核过程，不能声称已随本轮全部还原。
