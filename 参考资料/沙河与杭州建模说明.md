# 沙河与杭州建模说明

本次扩展日期：2026-09-12。新增沙河及杭州国际校园，原学院路模型继续保留。

## 数据与精度

两校区地图来自 OpenStreetMap API 0.6，原始 XML 与转换后的 GeoJSON 均在 `data/` 中。地图包含独立建筑轮廓、整体楼群、屋顶、用地边界和道路，各类对象不能直接统一拉高。

沙河展示53个楼体或楼群；杭州展示43个楼体或楼群，并在中央屋顶下独立标出9个功能楼体。这些是模型对象数量，不等于官方建筑总数。补绘建筑、缺失细节及近期建设变化仍需要现场资料校核。

已知尺度采用公开资料；其他尺寸按地图、照片或图纸比例估算。未获取完整施工图，没有逐栋立面测量，也未进行摄影测量或激光扫描。场地采用平地，树木、庭院绿岛、灯光及球场划线为示意。

## 沙河

- 新图书馆：采用官方公布的32米高度、地上6层、25.2米穹顶直径。根据建成照片制作底层柱廊、纵向幕墙格栅、屋顶中庭、穹顶及光伏板。位置参考OSM旧规划用地，外轮廓和各构件位置为估算，尚非竣工图轮廓。
- 主楼：保留南北向凹口与楼群轮廓；去掉整体外轮廓与A—F区重复挤出的问题。楼高、窗格和外观比例仍为估算。
- 依据官网图补绘西北侧配套楼、学生公寓及科研楼；五、六、七号楼维持“在建”标识，不宣称竣工。
- 修正原图书馆标签，旧馆显示为“二号教学楼（原图书馆）”。保留南湖，补充天空之镜及中央草坪，体育场按跑道处理。

官方校区示意图并非严格等比例测绘图；采用已知建筑中心配准后的补绘，只用于校园空间展示。不会修改上游OpenStreetMap。

## 杭州国际校园

范围为余杭区瓶窑镇双红桥街166号的杭州国际校园。OSM边界包含北侧地图资料较少的区域；该区域保持基础体量，不能据其景观表达判断真实建设状态。

- 飞翔屋顶：采用HENN公布的395米长度和168米跨度。按剖面关系生成两端抬高、中部下垂的曲面，区分端部屋面、天窗和中央透空格栅；具体曲率、最高最低点和结构间距按图比例估算。
- 屋顶下依据官方导览图划分C1—C9，包括会议及行政中心、图书馆、教学楼、科教美育中心和音乐厅等。隐藏屋顶可查看组团关系，内部楼体尺寸为简化重建。
- 体育馆：从官方建成照片提取波纹外壳、绕角层带、屋面曲线及南侧台阶。篮球、训练和游泳功能位于同一场馆，不画成三个互不相关的矩形馆。当前没有制作室内泳池和座席。
- 科研楼：将OSM的整体轮廓细分为带内院的楼体；庭院、连接翼和层高按设计总图与照片估算。
- 参照官网图核对宿舍编号，增加教学及生活区域的连接、入口广场、水景、绿岛及运动场。补绘位置和景观细节并非测绘数据。

## 实现及验证

GeoJSON经局部米制投影进入Three.js；普通楼体挤出保留轮廓，地标采用独立曲面和组合几何。环境、窗格及地标细节按材质合并，树木使用实例渲染。楼体点选与可隐藏屋顶保持独立。

交付前检查三校区加载、坐标及高度有效性、名称搜索、三种光照、屋顶开关、来源说明、数据下载、移动端布局，以及整体和场馆近景。检查报告与预览图保存在 `verification/`。
